# EventServiceApi
## Инструкция по запуску проекта

1. Установите .NET SDK версии 10.0 или выше. Вы можете скачать его с официального сайта [.NET](https://dotnet.microsoft.com/download/dotnet/10.0).
2. Склонируйте репозиторий проекта на ваш локальный компьютер.
3. Откройте терминал и перейдите в директорию проекта.
4. Выполните команду `dotnet restore`, чтобы восстановить все зависимости проекта.
5. Выполните команду `dotnet build`, чтобы собрать проект.
6. Выполните команду `dotnet run`, чтобы запустить проект.
7. После запуска проекта, вы сможете получить доступ к API по адресу `http://localhost:5263`.
8. Доступ к Swagger UI для тестирования API будет доступен по адресу `http://localhost:5263/swagger`.
9. Нужно добавить несколько событий в базу данных, чтобы проверить работу API. Вы можете использовать Swagger UI для добавления событий или использовать Postman для отправки POST-запросов на эндпоинт `/api/events`.
10. Для проверки наличия событий в базе данных, вы можете отправить GET-запрос на эндпоинт `/api/events` через Swagger UI или Postman.
11. Если хотить получить одно событие по его идентификатору, отправьте GET-запрос на эндпоинт `/api/events/{id}`, заменив `{id}` на идентификатор события.
12. Для изменения события, отправьте PUT-запрос на эндпоинт `/api/events/{id}`, заменив `{id}` на идентификатор события, и передайте обновленные данные события в теле запроса.
13. Для удаления события, отправьте DELETE-запрос на эндпоинт `/api/events/{id}`, заменив `{id}` на идентификатор события.
